# OW_mesh

Mesh files for the chams script.

## Install

1. Download `ow_meshes.zip` from the [latest release](https://github.com/meboiaa/OW_mesh/releases/latest).
2. Extract it into the folder that holds the script. It creates `ow_enma/meshes/`.

## Contents

- 1,891 `.chm` meshes, one per skin body
- 57 `.idx` skeleton indexes, one per hero
- `limits.txt`, the loader's buffer sizes
